# Quản Lý Sinh Viên - WinForms C\#

## Giới thiệu

Dự án "Quản Lý Sinh Viên" được phát triển bằng C# WinForms, giúp quản lý thông tin sinh viên một cách hiệu quả, bao gồm các chức năng như thêm, sửa, xóa và tìm kiếm sinh viên.

## Tính năng chính

- Quản lý danh sách sinh viên
- Tìm kiếm sinh viên theo tên, mã số
- Cập nhật, thêm mới và xóa thông tin sinh viên
- Giao diện trực quan, dễ sử dụng

## Yêu cầu hệ thống

- **Hệ điều hành:** Windows 10 trở lên
- **Phần mềm:** Visual Studio 2019/2022
- **Cơ sở dữ liệu:** SQL Server
- **Ngôn ngữ lập trình:** C# (WinForms)

## Hướng dẫn cài đặt

1. Clone repository:
   ```sh
   git clone <repository_url>
   ```
2. Mở dự án bằng Visual Studio.
3. Khôi phục database từ file `QLSV.bacpac` bằng SQL Server.
4. Chạy ứng dụng trong Visual Studio.

## Thư mục dự án

- `/QLSV_Gp.sln`: File solution của Visual Studio
- `/bin/`: Chứa các file build
- `/obj/`: Chứa file object khi build
- `/Database/QLSV.bacpac`: File backup cơ sở dữ liệu
- `/Source/`: Chứa mã nguồn chính của ứng dụng
